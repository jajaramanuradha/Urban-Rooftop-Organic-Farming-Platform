# AI-Powered Urban Rooftop Organic Farming Platform

Frontend student project using HTML, CSS and JavaScript.

## Files
- index.html — dashboard
- crops.html — crop management with localStorage
- ai-advisor.html — rule-based crop recommendation demo
- disease-detection.html — plant-health image upload demo
- weather.html — sample weather dashboard
- analytics.html — farm analytics
- css/style.css — common responsive styling
- js/*.js — page functionality
- images/ — project images

## Run
Extract the folder and open `index.html`. VS Code + Live Server is recommended.

## Important
The AI advisor, disease detection and weather pages are demo implementations. For a real final-year system, connect Python Flask/FastAPI, an ML/CNN model, live weather API, IoT sensors and MySQL/SQLite.

## Future Enhancements
IoT soil-moisture sensors, live weather API, expanded disease dataset, predictive analytics, automated irrigation, user authentication and database integration.
